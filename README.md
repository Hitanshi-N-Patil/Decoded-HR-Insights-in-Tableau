# 🚀 Decoded HR: Insights in Tableau  

Transforming HR data into powerful insights with an interactive Tableau dashboard.  
This project visualizes employee **attrition, workforce trends, demographics, and performance metrics** in a clean and engaging way.  

---

## 🔥 Why This Project?  
HR data often sits in spreadsheets without telling a story.  
With this dashboard, we **decode HR patterns** to help businesses:  
- Identify drivers of **attrition**  
- Track **employee satisfaction & performance**  
- Explore workforce **demographics**  
- Make **data-driven retention strategies**

## ⚡ Getting Started  

### 1️⃣ Download the Dashboard  
- Grab the `.twbx` file from `/dashboard`  
- Open it in **Tableau Desktop**  

### 2️⃣ Use Your Own Data  
- Replace `data/hr_dataset.csv` with your HR dataset  
- Refresh data source in Tableau  

### 3️⃣ Explore  
- Apply filters 🔍  
- Check attrition trends 📉  
- Visualize workforce dynamics 📊
